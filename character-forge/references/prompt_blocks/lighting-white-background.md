# Lighting And White Background

Insert this fixed light/background block near the end of `prompt_en`. Adapt only the list of highlighted surfaces when a character has different visible tools or clothing.

```text
Preserve one single soft neutral upper-left key light, mostly clean white with only a faint warm daylight tendency. Add very narrow pale cream-white painted cel-shading lit-edge highlights only on light-facing character surfaces such as hair tips, cheek edge, shoulder, collar edge, outer sleeve, forearm ridge, chest folds, belt buckle, badge or plastic card, trouser side folds, and shoe edges. These highlights must look attached to the character surface, not like glow. Keep the shadow side darker with minimal ambient fill and no second rim light. Keep a flat pure white background with no gradient, vignette, aura, halo, glow around the character, visible light source, or scenery.
```
