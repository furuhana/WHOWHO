# Footwear And Accessory Grammar

编码: UTF-8

鞋子和饰品与服装同级。它们必须改变身体读法、重心、职业识别或动作逻辑，不能只是装饰清单。

## 鞋履语法

```yaml
鞋履设计:
  鞋型原型:
    - "帆布低帮"
    - "高帮运动鞋"
    - "训练鞋"
    - "工装靴"
    - "骑行靴"
    - "乐福鞋"
    - "凉鞋"
    - "足袋靴"
  可变结构:
    - 名称: "雕塑变形底"
      作用: "把熟悉鞋面变成强记忆点。"
      规则: "鞋面原型仍可读，鞋底侧墙和底部轮廓必须说明。"
    - 名称: "分段外底"
      作用: "表现缓震、行动或机械结构。"
      规则: "至少说明前掌、中足、后跟其中两段。"
    - 名称: "外翻侧墙"
      作用: "扩大脚底面积，压低重心。"
      规则: "侧墙外翻但保持干净轮廓，不像融化或破损。"
    - 名称: "空腔鞋跟"
      作用: "建筑结构和轻量感。"
      规则: "必须保证站姿稳定。"
    - 名称: "踝部护框"
      作用: "强化防护、运动或勤务感。"
      规则: "护框位置在鞋口或脚踝，不吞掉小腿。"
    - 名称: "鞋面侧翼"
      作用: "提供速度感和包裹感。"
      规则: "侧翼与鞋带区、鞋头或后跟相连。"
```

鞋子生成必须回答:

- 原型是什么。
- 鞋底如何变形或分段。
- 鞋面有哪些切割。
- 鞋口如何接裤脚/袜子/护腿。
- 它如何服务角色重心。

禁止:

- 只写厚底鞋。
- 鞋底没有侧墙、分段、后跟、足弓或外翻结构。
- 鞋子像坏掉、脏掉、磨损掉。
- 真实品牌标志或专属图案。

## 饰品语法

```yaml
饰品结构作用:
  - 名称: "拉宽肩线"
    可用物: ["胸背带", "肩包带", "披肩", "护肩", "背包肩带"]
    规则: "说明连接点和肩部外框。"

  - 名称: "切分腰腹"
    可用物: ["宽腰带", "腰封", "工具带", "腰包", "围裙带"]
    规则: "说明腰线高度和扣件位置。"

  - 名称: "压低重心"
    可用物: ["腿包", "重靴", "大鞋底", "小腿护片", "侧挂工具"]
    规则: "说明位于大腿/小腿/脚部的哪一侧。"

  - 名称: "放大手部"
    可用物: ["手套", "护腕", "拳套", "前臂护片", "工具握把"]
    规则: "服务 WHOWHO 大手和前臂体块。"

  - 名称: "建立职业工具感"
    可用物: ["编号片", "扫描器", "小票夹", "钥匙环", "工具包", "笔夹"]
    规则: "小而清楚，贴身或挂在明确部位。"

  - 名称: "头颈外框"
    可用物: ["兜帽", "高领", "围巾", "护目镜", "帽檐", "面罩"]
    规则: "强化头颈和肩部关系，但不遮掉脸部可读性。"
```

饰品生成必须回答:

- 挂在哪里。
- 如何连接。
- 形状和体积是什么。
- 改变了哪段身体读法。
- 是否承担职业识别。

## 饰品复杂度

- 每套造型通常选 3 个饰品/小件。
- 至少 1 个饰品承担结构作用，而不是只做小装饰。
- 若服装已经复杂，饰品应承担功能和重心，不再增加图案噪音。
- 若服装很简洁，饰品可以承担主要记忆点，但必须贴身、可画、可读。
