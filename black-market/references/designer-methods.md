# Designer Method Library

编码: UTF-8

此文件记录可转译为 WHOWHO 服装、鞋履和饰品设计语法的设计师方法。它不是品牌模仿库，也不是来源标签库。

## 使用边界

- 默认把设计师方法转译成匿名结构语言，供三宅、黑商、缪斯、黑墙、阿佐特使用。
- 用户明确要求测试或引用设计师时，阿佐特可以在提示词中加入短句 `with design-method references to <names>`，但仍必须同时写出具体裁片、比例、工艺和鞋饰结构。
- 设计师名字只能作为高层方法提示，不能替代可生成的服装描述。
- 不复制品牌标志、专属图案、秀款身份、来源角色、广告语或商业商标。
- 不把人物穿成某品牌 cosplay。最终服装必须属于当前角色、职业和世界底盘。

## 方法条目

```yaml
- 来源参考: "Issey Miyake"
  匿名方法: "平面到立体"
  核心问题: "平面布料如何通过褶、折、热压、展开和身体运动形成空间。"
  可用操作:
    - "整衣压褶"
    - "折线控制运动方向"
    - "大块平面通过重复折线产生体积"
    - "衣服先保持基础款可读，再通过折线改变动态"
  可用部位: ["宽裤", "短外套", "长披层", "内搭侧片", "包体折边"]
  禁止误用:
    - "不要变成密集小纹理或微织纹"
    - "不要把褶皱画成脏乱皱纹"
    - "不要让褶线切碎 WHOWHO 胸腹主块"

- 来源参考: "Alexander McQueen"
  匿名方法: "解剖式戏剧裁剪"
  核心问题: "裁片如何强化肩、胸、腰、臀和背部张力，让服装产生角色神话。"
  可用操作:
    - "肩线外移"
    - "腰部急收"
    - "胸侧弧片"
    - "背部中心护板或脊线"
    - "衣摆尖角或开衩制造戏剧方向"
  可用部位: ["外套肩线", "胸腹护片", "腰封", "长外层", "靴筒"]
  禁止误用:
    - "不要变成历史戏服堆砌"
    - "不要用尖刺、破损或血污制造廉价戏剧性"
    - "不要削弱宽体胸腹和肩背体块"

- 来源参考: "Maison Margiela"
  匿名方法: "制作痕迹外露"
  核心问题: "把缝制、内衬、标签、反面结构和未完成边变成设计语言。"
  可用操作:
    - "反缝"
    - "外露内衬"
    - "错位门襟"
    - "未完成但干净的边"
    - "外置标签片或白色工艺标记"
  可用部位: ["门襟", "袖缝", "衣摆", "裤侧线", "包盖", "鞋舌"]
  禁止误用:
    - "不要变成破烂、脏污或废土感"
    - "不要让错位结构妨碍职业可读性"
    - "不要直接复制四角缝线等专属品牌符号"

- 来源参考: "Rick Owens"
  匿名方法: "身体建筑与垂坠体块"
  核心问题: "通过长线条、垂坠、厚靴、压低色块和极端比例建立身体建筑。"
  可用操作:
    - "长下摆垂坠"
    - "袖长过手或袖筒加量"
    - "厚靴压低重心"
    - "窄上长线与宽下重心对抗"
    - "单色大块用边界工艺分层"
  可用部位: ["长外套", "宽裤", "靴子", "兜帽", "披挂"]
  禁止误用:
    - "不要让角色变成全黑空壳"
    - "不要过度拉长腿部或削薄肩宽"
    - "不要用单色遮掉所有裁片信息"

- 来源参考: "Boris Bidjan Saberi"
  匿名方法: "工业层叠与解构束缚"
  核心问题: "通过绑带、层叠、压缩和粗粝结构制造人体装备感。"
  可用操作:
    - "外置绑带"
    - "层叠裤片"
    - "压缩袖口和裤口"
    - "包裹式靴筒"
    - "背部或腰侧工具挂点"
  可用部位: ["腰部系统", "裤腿", "前臂", "靴筒", "背包"]
  禁止误用:
    - "不要引入脏污、油渍、灰尘或破损"
    - "不要漂移到码头、货运或苦力方向"

- 来源参考: "Schiaparelli"
  匿名方法: "身体装饰与超现实焦点"
  核心问题: "用身体部位、饰品和夸张硬件制造单一强焦点。"
  可用操作:
    - "胸前硬质徽章"
    - "夸张扣具"
    - "身体轮廓式饰品"
    - "手部或耳颈焦点件"
  可用部位: ["胸口", "腰扣", "手套", "领口", "包具"]
  禁止误用:
    - "不要满身奇观"
    - "不要把饰品做成脸、皮肤或妆容评价"

- 来源参考: "Iris van Herpen"
  匿名方法: "生物波纹与技术骨架"
  核心问题: "材料像波纹、骨架、流体或生物组织一样生长，同时保持结构控制。"
  可用操作:
    - "放射状肋片"
    - "透明层和硬质边"
    - "波纹式外骨架"
    - "轻量重复片"
  可用部位: ["胸肩护片", "袖外侧", "裙摆或披片", "鞋面外壳", "包体"]
  禁止误用:
    - "不要变成密集噪点纹理"
    - "不要做全身不可动画化的过细结构"
    - "不要写真实 3D 打印质感，保持平面动画可读"

- 来源参考: "Issey Miyake / wearable transformation research"
  匿名方法: "衣服生命体与错肢穿法"
  核心问题: "衣服如何像有自主意识一样改变入口、袖位、内外面和穿着路径，但仍服务人体。"
  可用操作:
    - "错入口"
    - "第二袖口或 inactive sleeve opening"
    - "内外面互换"
    - "侧向穿入口"
    - "多穿法但保持单一人体"
  可用部位: ["兜帽外壳", "套头罩衣", "短外套", "背育克", "侧腰开口"]
  禁止误用:
    - "不要把第二袖口画成第二只手臂"
    - "不要让穿法异常变成身体畸形"
    - "不要牺牲脸、手、胸腹和动作可读性"

- 来源参考: "Maison Margiela / material plasticisation research"
  匿名方法: "材质封存与内外显影"
  核心问题: "透明、胶质、半硬材料如何封住标记、口袋、线迹或小物，让隐藏层变成可见信息。"
  可用操作:
    - "封存口袋"
    - "透明硬窗"
    - "外露挂面"
    - "内衬显影"
    - "半硬包盖"
  可用部位: ["胸袋", "袖袋", "包盖", "鞋跟", "门襟", "腰侧标记"]
  禁止误用:
    - "不要只写透明材质"
    - "不要满身塑料化"
    - "不要引入脏污、垃圾袋、可读品牌文字"

- 来源参考: "Maison Mihara Yasuhiro / everyday prototype disruption"
  匿名方法: "普通原型故障"
  核心问题: "普通衣服如何通过假袖、假层、错位拼接和熟悉鞋底变形产生异常，而不丢失日常原型。"
  可用操作:
    - "假袖挂层"
    - "错觉双前襟"
    - "错位口袋"
    - "熟悉鞋面加雕塑侧墙"
    - "日常原型轻微故障"
  可用部位: ["短外套", "牛仔外壳", "校队外壳", "工装裤", "帆布鞋", "运动鞋底"]
  禁止误用:
    - "不要直接复制品牌鞋型"
    - "不要变成搞笑拼贴"
    - "不要让故障破坏职业识别"

- 来源参考: "Schiaparelli / hard chic body focus"
  匿名方法: "硬件命名身体"
  核心问题: "用单一硬件、扣具、胸片、钥孔或手部件强调身体部位，把幻想压缩成一个清楚焦点。"
  可用操作:
    - "胸前单一硬件焦点"
    - "钥孔状扣具"
    - "腰部雕塑扣"
    - "手部硬件焦点"
    - "背部中心板"
  可用部位: ["胸口", "腰扣", "手套", "背板", "包体"]
  禁止误用:
    - "不要满身超现实饰品"
    - "不要使用五官、脸、皮肤或妆容评价"
    - "不要让硬件抢走职业和身体读法"

- 来源参考: "Mihara Yasuhiro"
  匿名方法: "熟悉原型加雕塑变形底"
  核心问题: "保留经典鞋面可读性，把鞋底、包边和侧墙变成手工雕塑焦点。"
  可用操作:
    - "雕塑变形鞋底"
    - "外翻橡胶侧墙"
    - "不均匀但干净的鞋底轮廓"
    - "熟悉帆布或运动鞋面保持稳定"
  可用部位: ["低帮鞋", "高帮鞋", "靴底", "鞋头包边"]
  禁止误用:
    - "不要直接复制品牌鞋型"
    - "不要把变形画成坏掉、脏掉或融化成污渍"
    - "不要只写厚底，必须说明侧墙和底部结构"

- 来源参考: "United Nude / Rem D Koolhaas"
  匿名方法: "鞋履建筑结构"
  核心问题: "把鞋跟、足弓、鞋面和鞋底当作承重结构和空间框架。"
  可用操作:
    - "空腔鞋跟"
    - "悬臂式鞋底"
    - "几何鞋面框架"
    - "足弓支撑外露"
  可用部位: ["鞋跟", "鞋底侧面", "鞋面框架", "凉鞋带"]
  禁止误用:
    - "不要让鞋变成不可穿的纯雕塑"
    - "不要牺牲角色站姿稳定性"

- 来源参考: "Tinker Hatfield"
  匿名方法: "性能叙事可视化"
  核心问题: "把运动需求、身体保护、气垫/窗口、绑带和标记转化为可见产品故事。"
  可用操作:
    - "性能窗口"
    - "鞋面侧翼支撑"
    - "踝部保护"
    - "鞋底分段缓震"
    - "小面积功能色标"
  可用部位: ["运动鞋", "训练鞋", "护踝", "鞋舌", "鞋底"]
  禁止误用:
    - "不要使用真实品牌标志"
    - "不要用功能词代替可见结构"

- 来源参考: "Guido Palau / Eugene Souleiman / Kamo Katsuya / Sam McKnight"
  匿名方法: "头部造型与服装结构同步"
  核心问题: "发型的体积、方向、质地和线条要回应衣服的肩颈、领口、姿态和时代。"
  可用操作:
    - "发型体积回应肩颈外框"
    - "发尾方向回应衣摆或袖面方向"
    - "干净束缚或锋利分区回应工艺边界"
  可用部位: ["发顶", "两侧", "后颈", "刘海方向"]
  禁止误用:
    - "不要让发型独立炫技而破坏服装重心"
    - "不要引入卷发方向，除非系统规则允许"
```

## 提示词引用规则

当用户允许在提示词中引用设计师时，阿佐特可以采用以下格式之一:

```text
with restrained design-method references to Issey Miyake garment pleating and Maison Margiela exposed construction, expressed through visible panel paths, clean piping, and controlled low-density markings
```

```text
with design-method references to Alexander McQueen anatomical tailoring and Mihara Yasuhiro sculptural sole logic, translated into broad shoulder panels, a cinched waist system, and a clean distorted shoe sole
```

引用后仍必须写出具体可见结构。不得只写 `in the style of <designer>`。
