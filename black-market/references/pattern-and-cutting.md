# Pattern And Cutting Grammar

编码: UTF-8

此文件规定服装花纹、裁片和工艺边界如何生成。目标是让衣服像被设计过，而不是在基础款上随机画线。

## 裁片路径规则

每个主要裁片路径应尽量说明:

```yaml
裁片路径:
  - 名称: "<胸侧弧形拼片 / 袖外断续压线 / 背部中心护板 / 裤侧楔形片>"
    起点: "<肩峰下方 / 领口边 / 腰侧 / 膝外侧 / 鞋口>"
    经过: "<胸肌外缘 / 肘关节前后断开 / 侧腰 / 大腿外侧>"
    终点: "<侧腰 / 前臂 / 下摆 / 小腿外侧 / 鞋底侧墙>"
    规则: "<避开关节 / 不切碎胸腹主块 / 服务肩宽 / 压低重心>"
```

## 身体适配

- WHOWHO 宽体角色的胸腹主块必须可读。裁片可以绕胸、托胸、框胸，但不能把胸腹切成碎图案。
- 肩峰、三角肌、前臂、手、腰腹、臀腿和靴子是主要结构锚点。
- 上身线条优先强化肩宽、胸侧和前臂，不要把躯干拉成长条。
- 下身线条优先压低重心、稳定脚底、强调大腿和鞋底体量。
- 肘、膝、踝处允许断开、错位或转折，避免线条像贴图一样跨过关节。
- 紧身或贴身层必须让胸肌、腹块和侧腹面通过干净大形体读出来。

## 图案策略

```yaml
图案策略:
  - 类型: "边缘纹"
    位置: ["领口", "袖口", "衣摆", "鞋口", "包边"]
    密度: "低"
    作用: "强调边界，不抢主体。"

  - 类型: "局部徽记"
    位置: ["背部中心", "胸前小块", "包盖", "鞋底侧墙", "袖章"]
    密度: "低"
    作用: "提供身份或记忆点。"

  - 类型: "断续条"
    位置: ["袖外侧", "裤侧", "鞋面侧翼", "背带"]
    密度: "中"
    作用: "建立运动方向或工程节奏。"

  - 类型: "低密度格纹"
    位置: ["宽裤", "围巾", "内层局部", "包体侧面"]
    密度: "中低"
    作用: "制造节奏，但必须保留大块明度。"

  - 类型: "放射肋片"
    位置: ["胸肩护片", "披片", "鞋面外壳", "包体"]
    密度: "中"
    作用: "制造生物/技术骨架感。"

  - 类型: "热压折线"
    位置: ["宽裤", "短外层", "披挂", "包体折边"]
    密度: "中"
    作用: "让平面布料形成可控体积。"
```

## 工艺边界词表

可用:

- 滚边
- 包边
- 压线
- 反缝
- 拉链牙
- 扣具
- 挂环
- 袖口硬扣
- 罗纹收口
- 抽绳
- 腰封
- 外露内衬
- 未完成但干净的边
- 热压折线
- 护片硬边
- 鞋底侧墙

## 密度配额

```text
大形体: 60%
中型裁片: 25%
小工艺: 10%
图案符号: 5%
```

执行方式:

- 大形体负责第一眼轮廓: 外套体积、裤型、鞋底、肩宽、腰部收束。
- 中型裁片负责设计感: 胸侧片、袖面片、裤侧片、护板、背板。
- 小工艺负责可信度: 滚边、扣具、拉链牙、压线、包边。
- 图案符号负责记忆点: 徽记、断续条、低密度边缘纹。

## 禁止

- 满铺小花纹。
- 微织纹、噪点、细小 speckle。
- 没有路径说明的随机线。
- 图案跨过关节而不转折。
- 所有部位同等复杂。
- 为了复杂而削弱身体主块。
- 把材质表现成真实细纹理贴图。
