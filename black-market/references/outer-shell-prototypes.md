# Outer Shell Prototype Library

编码: UTF-8

此文件专门扩充外层原型，防止 WHOWHO 服装反复退回普通衬衫、普通夹克和印花上衣。外层原型应按覆盖方式、长度、闭合方式、体积来源和职业来源选择。

## 硬规则

- 最终外层不得只写 `jacket`, `coat`, `vest`, `shirt jacket`, `outerwear`, `hoodie`。
- 最终外层必须精确到本文件的原型级别，或写出同等精度的新原型。
- 若造型含有衬衫、T恤、Polo 或制服衬衫，它们默认是内层或中层；主视觉必须由精确外层、马甲/护甲、腰部系统、腿部系统、鞋履系统、头颈系统或挂载系统承担。
- 披覆外层只能服务肩背、防护、天气、仪式、装备或动作释放，不能变成裙状、围裙状、拖地布片或下身主体。

## 原型字段

每个外层原型在库存或三宅记录中尽量回答:
