# Design Operators

编码: UTF-8

设计操作符用于把基础款加工成有设计逻辑的服装、鞋履和饰品。操作符不能单独进入最终提示词，必须落到部位、路径、工艺和身体作用。

## 核心原则

- 先保留基础款识别，再做结构加工。
- 每套造型至少使用 1 个结构变形、1 个裁片路径、1 个工艺边界、1 个记忆点。
- 复杂度配额默认: 大形体 60%, 中型裁片 25%, 小工艺 10%, 图案符号 5%。
- 高级感来自选择和控制，不来自满身细节。

## 操作符库

```yaml
设计操作符:
  - 名称: "错位"
    可用部位: ["门襟", "口袋", "扣具", "鞋带区", "包盖", "胸前标记"]
    作用: "打破基础款正中秩序，制造轻微不安或先锋感。"
    生成要求: "说明偏移方向和偏移后的收束点。"
    禁忌: "不要让错位变成画面错误或左右结构混乱。"

  - 名称: "膨胀"
    可用部位: ["肩部", "袖筒", "裤管", "鞋底", "手套", "包体"]
    作用: "增加体块、力量和外轮廓。"
    生成要求: "膨胀必须被腰带、袖口、裤口、鞋口或硬件收住。"
    禁忌: "不要把宽体角色变成长腿瘦身或漂浮大衣。"

  - 名称: "压缩"
    可用部位: ["腰部", "袖口", "裤脚", "靴口", "前臂", "领口"]
    作用: "控制体积，强调力量从收束点外溢。"
    生成要求: "压缩点要与宽肩、胸腹、手臂或腿部形成对比。"
    禁忌: "不要用紧身裤脚、 jogger cuff 或裤子塞袜子破坏袜裤规则。"

  - 名称: "分段"
    可用部位: ["护片", "鞋底", "裤腿", "袖面", "背板", "腰封"]
    作用: "制造工程感、运动方向和可读结构。"
    生成要求: "分段要有顺序和大小变化，大段在主视觉，小段只做连接。"
    禁忌: "不要平均切碎全身。"

  - 名称: "外露"
    可用部位: ["反缝", "包边", "内衬", "拉链牙", "扣具", "标签片"]
    作用: "让制作逻辑成为设计信息。"
    生成要求: "外露结构保持干净、平整、动画可画。"
    禁忌: "不要变成脏污、破烂、磨损或噪点纹理。"

  - 名称: "折叠"
    可用部位: ["宽裤", "披挂", "短外层", "包体", "领口"]
    作用: "用布面折线形成体积和运动方向。"
    生成要求: "折线应沿重力、动作或身体转折走。"
    禁忌: "不要变成随机皱纹。"

  - 名称: "框架"
    可用部位: ["肩背带", "胸带", "鞋面框", "包体外框", "护甲边"]
    作用: "把软服装变成有承重感的身体结构。"
    生成要求: "说明框架压在哪里、连接哪里、如何改变身体读法。"
    禁忌: "不要全身到处加带子。"

  - 名称: "开口"
    可用部位: ["前襟", "侧缝", "袖口", "背部", "裤腿", "鞋口"]
    作用: "释放动作、露出内层或制造层次。"
    生成要求: "开口必须露出有用内层、肌肉体块或功能结构。"
    禁忌: "不要无理由暴露或色情化。"

  - 名称: "包覆"
    可用部位: ["兜帽", "高领", "围巾", "护腕", "护腿", "靴筒"]
    作用: "提供遮蔽、防护、仪式感或职业工具感。"
    生成要求: "包覆边界要清楚，不能吞掉头脸或手脚可读性。"
    禁忌: "不要遮掉脸部可读性。"

  - 名称: "悬挂"
    可用部位: ["腰侧包", "腿包", "编号片", "垂带", "钥匙串", "工具环"]
    作用: "提供生活或职业线索，改变重心。"
    生成要求: "说明挂点、长度、形状和是否贴身。"
    禁忌: "不要让小件散落成背景道具。"

  - 名称: "错入口"
    可用部位: ["侧腰", "门襟", "后肩", "领口", "袖口"]
    作用: "改变衣服的穿着路径，让基础款出现结构事件。"
    生成要求: "说明主入口、异常入口和收束点；异常入口必须仍属于衣服，不属于身体。"
    禁忌: "不要画成多手臂、身体畸形或不可穿纯概念。"

  - 名称: "反穿"
    可用部位: ["内衬", "挂面", "反缝", "背面结构", "下摆"]
    作用: "把通常隐藏的反面结构转成外观。"
    生成要求: "说明哪一层被翻到外面，以及边界如何保持干净。"
    禁忌: "不要变成破烂、脏污、毛边噪点或品牌符号。"

  - 名称: "封存"
    可用部位: ["胸袋", "袖袋", "包盖", "腰侧标记", "鞋跟", "胸前硬片"]
    作用: "把标记、小物、线迹或口袋内容封进半硬或透明层。"
    生成要求: "说明被封存物、封存材料、硬边边界和面积控制。"
    禁忌: "不要只写透明，不要满身封存，不要出现可读品牌文字。"

  - 名称: "生长"
    可用部位: ["兜帽", "袖外侧", "肩背", "披覆外层", "包体"]
    作用: "让衣片像从基础款上延展或增殖，形成生命体式外壳。"
    生成要求: "说明从哪里生长、沿哪里延展、在哪里被扣具或包边收住。"
    禁忌: "不要做随机触手、噪点细节或不可动画化小结构。"

  - 名称: "错觉拼接"
    可用部位: ["袖子", "前襟", "口袋", "鞋底", "裤侧", "背片"]
    作用: "让熟悉原型出现假层、假袖或错位部件。"
    生成要求: "保持基础款原型可读，错觉只占一个主部位。"
    禁忌: "不要拼贴过载，不要复制来源款，不要变成画面错误。"

  - 名称: "单片包覆"
    可用部位: ["肩背", "胸侧", "腰侧", "兜帽", "披覆外层"]
    作用: "用一片连续材料绕身成壳，改变外轮廓和空隙。"
    生成要求: "说明固定点、包边、空隙和身体服务目标。"
    禁忌: "不要裙化、围裙化、拖地或吞掉四肢。"
```

## 设计生成公式

```text
基础款原型
+ 1-2 个设计操作符
+ 1 个身体适配目标
+ 1 个裁片路径
+ 1 个工艺边界
+ 1 个鞋履或饰品记忆点
+ 复杂度配额检查
```

## 假高级黑名单

- 满身随机线条。
- 全身小图案满铺。
- 无功能的赛博发光线。
- 衣服像贴图，不像裁片。
- 鞋底只是变厚，没有鞋底侧墙、分段、足弓或后跟结构。
- 饰品只是挂件，不改变肩线、腰腹、手部、腿部、重心或职业读法。
- 单色大块没有边界工艺、层次或材料分区。
- 用 dirty, worn, distressed, scuffed, frayed, noisy texture 伪装设计感。
